# RapidMap Assessment

Technical assessment for [RapidMap](https://www.rapidmap.com/). The code for each task can be found in the links below, or under the appropriate directory. Each task folder contains an `INSTRUCTIONS.md` file with the task brief, and a `README.md` containing details of the implementation and assumptions made.

## Tasks

- [Task 1 — Coordinate transformation](task1/README.md)
  - [Web Demo](https://wgs84-mga2020.streamlit.app/).
- [Task 2 — Rasterisation at scale](task2/README.md)
- [Task 3 — Object detection](task3/README.md)
